Privacy notice

Maltipoo Sisters doesn't collect any information about you or your children. No accounts, no ads, no tracking, no chat.

What the game saves on your device

To remember your choices, the game saves two small things in this browser's storage (localStorage): your settings (language, a developer option) and your progress (which places you finished, your best time and how many treats you found). They stay on this device and are never sent anywhere.

To delete them: in the game, go to Settings → Reset progress, or clear this site's data in your browser settings.

Hosting

The game is a website hosted on GitHub Pages. Like any website host, GitHub receives standard technical information to deliver the pages, such as your IP address and browser type. See GitHub's privacy statement. The game loads nothing from other websites.

Children

The game is made for families and children. Because it collects no personal information from anyone, there is nothing to ask parents' permission for.

Changes and contact

If this ever changes, this page will be updated first. Made by Nick Grechuha. Questions: open an issue on GitHub.

Політика конфіденційності

Maltipoo Sisters не збирає жодної інформації про вас чи ваших дітей. Жодних облікових записів, реклами, стеження чи чату.

Що гра зберігає на вашому пристрої

Щоб пам'ятати ваш вибір, гра зберігає дві невеликі речі у сховищі цього браузера (localStorage): ваші налаштування (мова, опція для розробників) і ваш прогрес (які місця ви пройшли, найкращий час і скільки смаколиків знайшли). Вони залишаються на цьому пристрої й нікуди не надсилаються.

Щоб їх видалити: у грі відкрийте Налаштування → Скинути прогрес або очистьте дані цього сайту в налаштуваннях браузера.

Хостинг

Гра — це вебсайт на GitHub Pages. Як і будь-який хостинг, GitHub отримує стандартні технічні дані, щоб показати сторінки, наприклад вашу IP-адресу й тип браузера. Див. заяву GitHub про конфіденційність. Гра нічого не завантажує з інших сайтів.

Informacja o prywatności

Maltipoo Sisters nie zbiera żadnych informacji o Tobie ani o Twoich dzieciach. Bez kont, reklam, śledzenia i czatu.

Co gra zapisuje na Twoim urządzeniu

Aby pamiętać Twoje wybory, gra zapisuje dwie małe rzeczy w pamięci tej przeglądarki (localStorage): Twoje ustawienia (język, opcja dla twórców) i Twoje postępy (które miejsca ukończono, najlepszy czas i liczbę znalezionych smaczków). Zostają na tym urządzeniu i nigdzie nie są wysyłane.

Jak je usunąć: w grze wejdź w Ustawienia → Wyzeruj postępy albo wyczyść dane tej strony w ustawieniach przeglądarki.

Hosting

Gra to strona internetowa na GitHub Pages. Jak każdy hosting, GitHub otrzymuje standardowe dane techniczne potrzebne do wyświetlenia stron, np. Twój adres IP i rodzaj przeglądarki. Zobacz oświadczenie GitHub o prywatności. Gra niczego nie pobiera z innych stron.

Dzieci

Gra jest stworzona dla rodzin i dzieci. Ponieważ nie zbiera od nikogo danych osobowych, zgoda rodziców nie jest potrzebna.
